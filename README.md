# Conexium Engenharia

Site institucional da **Conexium Engenharia** — engenharia elétrica, consultoria técnico-regulatória e perícias técnicas para o setor elétrico.

A Conexium Engenharia se posiciona como empresa técnica premium especializada exclusivamente em três pilares fundamentais:

1. **Engenharia e Projetos Elétricos**
2. **Consultoria Técnico-Regulatória**
3. **Perícias, Quesitos e Pareceres Técnicos**

---

## Stack Técnica

- **Framework:** Astro (SSG - Static Site Generation)
- **Estilização:** Tailwind CSS & Design System com tokens próprios
- **Linguagem:** TypeScript
- **Testes Unitários:** Vitest
- **Testes E2E:** Playwright
- **Gerenciador de Pacotes:** pnpm

---

## Comandos de Desenvolvimento

```bash
# Instalar dependências
pnpm install

# Verificação de qualidade (Lint institucional)
pnpm lint

# Verificação estática de tipos
pnpm typecheck

# Execução de testes unitários
pnpm test

# Compilação estática de produção
pnpm build

# Auditoria de integridade de links internos
pnpm audit:links

# Testes de ponta a ponta (E2E)
pnpm test:e2e
```
